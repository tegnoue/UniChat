UniChat
------------------------------------
Projeto voltado à construir um aplicativo de chat com protocolo próprio (fins de estudo)

Entrada: 'USER' <usuario>
Ver todos online: "SALL"
Ver se usuario existe: "EXIN" <usuario>
Mandar msg: "SEND" <destino> <mensagem>
Criar lista de trasmissão: "TRNS" <usuario1, usuario2, usuario3> <mensagem>
Saida: "QUIT"
